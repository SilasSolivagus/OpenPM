欢迎使用 OpenPM 产品经理工作台

你不需要记任何复杂命令。平时就像和产品助理聊天一样，复制下面这几句大白话发给你的 AI 工具即可。

1 日常最常用的 5 句大白话（点右侧按钮一键复制）

场景 A · 从 0 到 1 做全新需求（Wiki 是空的也能直接跑）
我要做一个【填写你的新功能想法】需求，先帮我出结构化 PRD 和可点选交互原型
场景 B · 改线上已有老功能（自动标出 5% 琥珀橙研发增量）
这是旧版文档/链接，本期要增加【填写改动点】，先拉取对比再出新版原型
场景 C · 开完多人评审会（汇总多位同事导出的备注并检测冲突）
我把前端、后端和测试导出的评审文件放进项目目录了，帮我合并检查有没有冲突，确认后精准回写
场景 D · 确认定稿推送公司平台（企微 / Confluence / 飞书 / 本地归档）
这版定稿了，帮我打包左图右文对照表推到 Wiki / 企业微信
场景 E · 一句话无损升级最新版 OpenPM（不丢密钥、不覆盖现有需求）
帮我运行 python3 scripts/upgrade_openpm.py 无损升级 OpenPM 并重编当前项目

2 怎么开多人需求评审会？（所见即所得点选批注）

① 把单文件 HTML 丢进群里

每个需求生成的 walkthrough.html 是纯离线单文件，直接发给前端、后端、测试，双击就能在浏览器打开。

② 填署名 + 点按钮插 @组件

同事点右上角「+ 记备注」，填上自己的名字（如 前端-王工），直接点界面上的按钮自动插入 @[组件名] 写意见，点「导出 .jsonl」发回给你。

③ 多人意见合并与冲突保护

你可以在网页抽屉点「导入合并」一键汇总所有人的备注；也可以直接丢给 AI，遇到两个人改同一个按钮且意见相反时，AI 会先弹窗让你拍板，绝不乱改。

④ 自动攒经验越用越懂你

每次改稿和定稿会在本地自动记分、记错题；每满 3 个需求提醒你一键「复盘优化」，把你的个人品味永久写进 evals/taste-profile.md。

3 你的文件存在哪？安全吗？（100% 零遥测承诺）

本地业务目录：projects/<产品名>/

所有 PRD、线框原型、流程图和历史快照都在本地文件夹里，你可以直接用 Obsidian 打开管理。

密钥隔离与零遥测隐私保护

平台密钥只保存在你本机的 .env.local（已被 Git 严格屏蔽）；OpenPM 零后台数据上报、零遥测服务器，未点推送前绝不联网外传。
