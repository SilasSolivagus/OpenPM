OpenPM Product Manager Quickstart

欢迎使用 OpenPM 产品经理工作台

Zero CLI flags to memorize. Copy any plain-language prompt below and paste it directly into Claude Code, Cursor, Codex, Antigravity, WorkBuddy, or dsh.

不需要背任何命令行参数。平时就像和产品助理对话一样，点击右侧按钮一键复制下面这几句大白话发给你的 AI 工具即可。

2 How Multi-Reviewer Spec Crits Work 怎么开多人需求评审会？（所见即所得点选批注）

1. Share the standalone HTML file ① 把单文件 HTML 丢进群里

Every walkthrough.html is a self-contained offline file. Drop it into Slack, WeCom, or Feishu; teammates double-click to open it in any browser.

每个需求生成的 walkthrough.html 是纯离线单文件，直接发给前端、后端、测试，双击就能在浏览器打开。

2. Sign name + click UI to insert @[Component] ② 填署名 + 点按钮插 @[组件名]

Reviewers click "+ Add Note", enter their name (e.g. Maya - Eng), click any button on the canvas to insert @[Component], and export .jsonl.

同事点右上角「+ 记备注」，填上署名（如 前端-王工），直接点界面上的按钮自动插入 @[组件名] 写意见，点「导出 .jsonl」发回给你。

3. Merge & automatic conflict check ③ 多人意见合并与冲突保护

Use "Import & Merge" inside the drawer or hand all .jsonl files to your agent. Conflicting edits on the same control are surfaced for your decision before anything changes.

可在网页抽屉点「导入合并」汇总备注，或直接丢给 AI：多人改同一按钮且意见相左时，AI 会先列出来请你拍板，绝不乱改其他页面。

4. Double-blind A/B taste learning ④ 双盲裁判自动沉淀个人品味

Every 3 shipped specs, say Run a taste retrospective. A randomized blind A/B judge verifies rules and saves your recurring preferences into evals/taste-profile.md.

每次改稿和定稿会在本地自动记分记错题；每满 3 个需求说一句「复盘优化」，经随机双盲裁判验证后永久固化进 evals/taste-profile.md。

3 Where Files Live & 100% Zero-Telemetry Privacy 你的文件存在哪？安全吗？（100% 零遥测承诺）

Local workspace: projects/<product>/ 本地业务目录：projects/<产品名>/

All PRDs, grayscale wireframes, orthogonal flows, and version snapshots live in plain local folders ready to open in Obsidian.

所有 PRD、纯灰阶线框原型、流程图和历史快照都在本地文件夹里，可直接用 Obsidian 打开管理。

Isolated secrets & native single-doc push 密钥隔离与原生单篇在线文档交付

API keys stay strictly in git-ignored .env.local. Zero analytics or telemetry ever run; remote sync happens only when you push a single native doc to WeCom, Confluence, or Feishu.

平台密钥仅保存在本机 .env.local（已被 Git 严格屏蔽）；零后台遥测上报，确认定稿时只推送单篇原生可读在线文档，绝不乱传工程源文件。
