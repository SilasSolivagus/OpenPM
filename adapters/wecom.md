# 企业微信适配器（`wecom` · 左原型右说明交付与诚实状态码规范）

本适配器用于对接**企业微信在线文档 / 微盘知识库**，严格执行以下 6 条工程铁律：

1. **支持同页多状态对比子表，严禁主图套娃与内容重复**：外层三列表格 **`序号 | 页面 | 需求说明`** 为主容器——当同一页面存在多个状态/异常态（如多账号态 / 单账号态 / 空态 / 校验报错态）时，允许通过 `spec.json` 的 `state_groups` 或 `prd.md` 内的 `| 原型 | 说明 |`（配 `![状态名](page_id)`）在父页面右栏内嵌多状态图文对比子表（公共规则写在外层，各态差异规则写在子表）；**依然严禁把外层左栏同一张主图与外层已写规则原样重复套娃复述一遍**（以 `prd.md` 为单一权威信息源，每条业务规则全篇只准出现一次）。
2. **多端变体（`variant_of`）完整并入**：同一页面的 `Web / PC` 与 `App 375px` 等所有 `variant_of` 变体截图自动配齐端形态标签，并列排入该条目的左栏。
3. **100% 强制纯灰阶**：截图渲染层强制注入 `filter: grayscale(100%) !important`，文档表格与链接样式全灰阶，彻底杜绝蓝色复选框、蓝色链接或彩色控件混入。
4. **跨页上下文不断裂**：网页版左栏原型 `sticky` 吸顶跟随并带 `#序号 · 页面名` 胶囊；Word `.docx` 开启 `<w:tblHeader/>` 跨页自动重复表头，超长页面自动拆分为 `N-续` 续行并在左栏配齐变体图与归属标题。
5. **受限沙箱截图失败立即报错中止（退出码 `3`）**：当受限运行环境阻止无头 Chrome 截图时，`wiki_sync.py` 绝不静默产出缺图残次文档，而是立即返回退出码 `3`（`SCREENSHOT_CAPTURE_FAILED`），Agent 必须申请放宽沙箱权限重试。
6. **严禁假成功（退出码 `2`）**：
   - 企微**智能机器人**的 `WECOM_BOT_ID`（非 `ww` 开头的企业 `CorpID`）**不能**调用企微开放平台的 `wedoc/create_doc` 在线文档创建接口（调用必报 `40013 invalid corpid`）；只有企业自建应用的 `WECOM_CORP_ID` + `WECOM_CORP_SECRET` 才能直连该 API。
   - 当远端 API 未真正上传成功时，`wiki_sync.py push` 会先在本地 `wiki-export/` 生成完整的 `<项目名>-产品方案.docx` 与 `wiki-page.html`，然后**诚实返回退出码 `2`（`REMOTE_PUSH_NOT_UPLOADED`）**。
   - **Agent 收到退出码 `2` 时严禁向 PM 谎报“已同步到企微”！** 必须：
     - 若客户端已挂载授权的企微/微盘 MCP 工具：只把单篇 `<项目名>-产品方案.docx`（及可选 `walkthrough.html.zip`）上传至目标目录（严禁上传 `project-context.md`、裸 `prd.md`、`spec.json`）；
     - 若无上传权限：如实告知 PM 本地已生成好 `<项目名>-产品方案.docx`（拖入企微或导入即可直接作为在线文档打开）及带「一键复制左图右文全表」按钮的 `wiki-page.html`。
