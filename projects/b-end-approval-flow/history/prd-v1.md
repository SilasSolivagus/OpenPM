# 企业采购审批流 PRD（v1.0 历史归档）

> 来源：`wiki-remote/procurement-approval-v1.md`（同步自 local-obsidian）

## 1. 流程概览

- **入口**：企业管理后台 -> 采购管理 -> 采购申请列表
- **表单字段**：采购金额（元）、采购事由
- **审批链路**：申请人提交 -> 直属主管单级审批 -> 审批完成 / 驳回结束

## 2. 功能清单（v1.0）

| 模块 | 页面 | 说明 |
| :--- | :--- | :--- |
| 采购列表 | 采购申请列表页 | 展示历史采购单状态，提供「新建采购单」按钮 |
| 采购填报 | 新建采购申请单页 | 填写金额、事由并提交 |
| 主管审批 | 直属主管审批弹窗 | 仅支持「同意」「驳回」两个动作 |
| 结果页 | 审批结果页 | 展示最终审批状态；驳回后流程终止，不保留草稿 |
