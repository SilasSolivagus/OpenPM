# 企业采购审批流需求说明（v1.0）

## 1. 背景与目标

为规范内部办公物资、软件订阅与外包服务采购，建立线上化「采购单」提交与审批流程，替代线下邮件与纸质签字。

## 2. 审批规则（v1.0）

1. **发起申请**：员工在企业管理后台「采购申请列表」新建采购单，填写采购金额与采购事由后提交。
2. **单级审批**：所有采购单统一路由至申请人所在部门的「直属主管」进行单级审批。
   - **同意**：采购单状态流转至「已通过」，流程结束。
   - **驳回**：采购单直接标记为「已作废 / 已驳回」，不支持保留草稿，如需重新申请须新建采购单重新填写。
3. **暂不支持**：
   - 不区分采购金额大小，无财务复核节点。
   - 不支持加签与驳回重提。
